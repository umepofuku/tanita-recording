# 体組成ログ

体組成計（タニタ）の数値を記録して、グラフで推移を見るための、1ファイルのWebアプリです。
ビルド不要・外部ライブラリなし。`index.html` をブラウザで開くだけで動きます。

## 機能

- 8項目を記録: 体重、BMI、体脂肪率、筋肉量、推定骨量、内臓脂肪レベル、基礎代謝、体内年齢
- 日付に加えて計測時刻（HH:MM）も記録。同じ日に何回測っても、日時が違えば別の記録
- 項目ごとの折れ線グラフ。期間切り替え（30日 / 90日 / 1年 / 全期間）。期間は、その項目の最新の記録から数える
- 履歴の編集・削除（削除は2回押し）、入力値の範囲チェック
- CSVの書き出し・読み込み（Excelで保存し直した `2026/10/4` 形式の日付や、時刻列のない旧形式も読めます）
- ライト/ダーク表示、スマホ向けレイアウト

## データの保存先

記録は、使っているブラウザの `localStorage`（キー: `taiso-log-v1`）にだけ保存されます。サーバーには送信されません。

- ブラウザのデータを消すと記録も消えます。ときどき「CSVを書き出す」でバックアップしてください
- ドメインごとに別のデータになります（ローカルで開いた場合、GitHub Pages、Claude上の公開ページは、それぞれ別）。移行はCSVの書き出し→読み込みで行います
- 1件あたり約145バイトです

## GitHub Pages で公開する

1. リポジトリの Settings → Pages
2. Source を「Deploy from a branch」、Branch を `main` / `(root)` にして保存
3. `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます

## 動画・写真から数値を読み取る機能について

この機能は、Claude上で公開したページでのみ動きます（ClaudeのAI読み取り機能を使うため）。
GitHub Pagesなど、それ以外の場所では、読み取りボタンは表示されず、手入力で記録します。

## CSV形式

```
日付,時刻,体重(kg),BMI,体脂肪率(%),筋肉量(kg),推定骨量(kg),内臓脂肪(レベル),基礎代謝(kcal/日),体内年齢(歳)
2026-10-22,07:30,44.95,20.0,20.9,33.6,2.0,3,1003,36
```

- 文字コードはUTF-8（BOMつき）、改行はCRLF
- 時刻と各数値は空欄可。読み込み時、空欄は既存の値を上書きしません
- 時刻列のない旧形式（`日付,体重(kg),…`）も読み込めます

## プライバシー

体組成は健康に関する個人情報です。計測した動画・写真・書き出したCSVは、公開リポジトリにコミットしないでください（`.gitignore` で `*.csv` `*.mov` `*.mp4` などを除外しています）。
